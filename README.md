# School Management System

## Project Overview

The School Management System is a MySQL-based relational database project designed to manage student details, subjects, examinations, and marks. It uses primary keys and foreign keys to connect related tables and SQL queries to retrieve and analyze academic information.

## Features

- Manage student records
- Manage subject details
- Store examination information
- Store and manage student marks
- Retrieve and filter academic records
- Calculate average and highest scores
- Display pass or fail status
- Perform SQL-based data analysis

## Tech Stack

- MySQL
- SQL
- MySQL Workbench

## Setup and Run

1. Install MySQL and MySQL Workbench.
2. Create a new database.
3. Create the required tables.
4. Insert the provided records.
5. Run the SQL queries in MySQL Workbench.

## Environment Variables

No environment variables are required for this project.

## Database Notes

The database contains four main tables:

- students
- subjects
- exams
- marks

The marks table connects students, subjects, and exams using foreign keys.
